# edex-ui-rs

Port di [eDEX-UI](https://github.com/GitSquared/edex-ui) da Electron a Rust (egui con backend OpenGL), pensato per PC vecchi con GPU datate.

Stato: versione Windows. Include terminale (ConPTY/PowerShell), orologio, info di sistema, CPU, RAM, processi, rete e file browser con tema tron.
Da fare: audio, tastiera virtuale, globo, altri temi, build Linux.

La build esce dalle GitHub Actions (artifact `edex-ui-rs-windows`).
